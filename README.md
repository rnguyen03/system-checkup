# system-checkup

A [Noctalia](https://github.com/noctalia-dev/noctalia) plugin: a
plain-language Arch Linux maintenance checklist and log-activity feed. See
[`system-checkup/README.md`](system-checkup/README.md) for the plugin
itself.

## Using this as a plugin source

```sh
noctalia msg plugins source add system-checkup path /path/to/this/checkout
noctalia msg plugins enable rnguyen03/system-checkup
```

`catalog.toml` at the repo root is auto-generated by CI on every push to
`main` — don't hand-edit it.
